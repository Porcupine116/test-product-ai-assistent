# Product AI Assistant

AI-помощник для подготовки черновиков товарных карточек контрольно-измерительных приборов для B2B-интернет-магазина.

## Возможности

- Принимает информацию о товаре в формате JSON.
- Генерирует SEO-заголовок до 70 символов.
- Создаёт SEO-описание объёмом 800–1200 символов.
- Формирует список поисковых запросов.
- Создаёт коммерческий блок для менеджера.
- Переносит технические характеристики из исходных данных.
- Определяет отсутствующие сведения о товаре.
- Проверяет числовые значения в сгенерированном тексте.
- Обрабатывает ошибки API и некорректные входные данные.

## Технологии

- Python 3.11+
- FastAPI
- Pydantic
- OpenAI Python SDK
- OpenRouter API
- HTML, CSS, JavaScript

## Установка

Клонировать репозиторий:

```bash
git clone <repository-url>
cd product-ai-assistant
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать его.

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Конфигурация

Создать файл `.env` на основании `.env.example`.

Добавить API-ключ OpenRouter:

```dotenv
OPENROUTER_API_KEY=your_api_key
OPENROUTER_MODEL=openai/gpt-4o-mini
OPENROUTER_SITE_URL=http://localhost:8000
OPENROUTER_APP_NAME=Product AI Assistant
```
А так же добавить Proxy

```dotenv
OPENROUTER_PROXY=http://LOGIN:PASSWORD@HOST:PORT
```

## Запуск

```bash
uvicorn app.main:app --reload
```

После запуска интерфейс будет доступен по адресу:

http://127.0.0.1:8000

Документация API:

http://127.0.0.1:8000/docs

Проверка состояния сервиса:

http://127.0.0.1:8000/api/health

## API

### POST /api/generate

Принимает JSON с информацией о товаре.

Пример запроса:

```json
{
    "name": "Манометр показывающий DM 02",
    "manufacturer": "Манотомь",
    "specs": {
        "диапазон измерений": "0–1,6 МПа",
        "класс точности": "1,5",
        "присоединение": "G1/2",
        "диаметр корпуса": "100 мм"
    },
    "description": "Прибор предназначен для измерения избыточного давления."
}
```

Результат содержит:

- Название товара и производителя.
- SEO-заголовок.
- SEO-описание.
- Структурированный список характеристик.
- Поисковые запросы.
- Коммерческий блок.
- Перечень отсутствующих данных.

## Принятые технические решения

**FastAPI и Pydantic**

FastAPI используется для HTTP API и обработки запросов. Pydantic обеспечивает валидацию входных данных и структуры ответа.

**OpenRouter API**

Для взаимодействия с LLM используется OpenRouter через OpenAI-совместимый API. Модель задаётся через переменную окружения, поэтому её можно заменить без изменения бизнес-логики.

**Разделение промпта и сервиса LLM**

Инструкция для модели находится отдельно от логики HTTP-запросов. Это упрощает изменение и тестирование промпта.

**Защита от выдуманных характеристик**

Модели запрещено добавлять технические значения, отсутствующие в исходных данных. Структурированные характеристики переносятся в результат непосредственно из входного JSON.

Дополнительно проверяются числовые значения в сгенерированных текстовых полях. При обнаружении неподтверждённых чисел генерация отклоняется.

**Обработка неполных данных**

Сервис проверяет отсутствие основных полей и объединяет результаты этой проверки с дополнительными замечаниями модели.

## Ограничения

- Контроль числовых значений не является полноценной семантической проверкой текста.
- Корректность технического смысла необходимо дополнительно проверять перед публикацией.
- Качество результата зависит от исходных данных и выбранной LLM.
- Проект является прототипом и не содержит базы данных, авторизации и CMS.
- Результат генерации представляет собой черновик, требующий проверки контент-менеджером.
